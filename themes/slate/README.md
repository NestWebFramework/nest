# Slate

A modern dark look with a header that stays on top, rounded cards and teal accents; light by day.

**Version 0.1.1** · theme · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-theme-slate` |
| name in a manifest | `slate` |
| category | look |
| reference | https://nest-framework.org/docs/reference/themes/slate |

## Using it

In an application's `module.yml`:

```yaml
application:
  theme: slate
```
