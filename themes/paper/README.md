# Paper

An editorial look, a masthead and a serif to read by, on warm paper; dark at night.

**Version 0.1.1** · theme · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-theme-paper` |
| name in a manifest | `paper` |
| category | look |
| reference | https://nest-framework.org/docs/reference/themes/paper |

## Using it

In an application's `module.yml`:

```yaml
application:
  theme: paper
```
