# Hello, Nest

**Version 0.2.0** (in `module.yml`; raise it there and here together) · port 8100 · part of Nest

The smallest Nest application: a page, to try Nest out.

```sh
uv run nest run applications/hello        # from Nest's repository: http://127.0.0.1:8100/
uv run nest plan applications/hello       # what it is made of
```

Running it on a server: `uv run nest run applications/hello`.
