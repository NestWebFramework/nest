# Redirects

Old addresses sent on to new ones, with hit counts, an editor and CSV imports.

**Version 0.1.0** · module · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-redirects` |
| name in a manifest | `redirects` |
| category | seo |
| reference | https://nest-framework.org/docs/reference/modules/redirects |

## Using it

In an application's `module.yml`:

```yaml
modules:
  - name: redirects
    route: /redirects
```
