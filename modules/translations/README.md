# Translations

Every module's records in every language of the site: the editors' fields, what is missing, a draft or outdated, an editor beside the original, export and import.

**Version 0.1.0** · module · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-translations` |
| name in a manifest | `translations` |
| category | content |
| reference | https://nest-framework.org/docs/reference/modules/translations |

## Using it

In an application's `module.yml`:

```yaml
modules:
  - name: translations
    route: /translations
```
