# Admin panel

One admin shell gathering the admin pages of every module an application includes.

**Version 0.2.3** · module · works with Nest `>=0.4.3,<1` · licence MIT

| | |
|---|---|
| package | `nest-admin` |
| name in a manifest | `admin` |
| category | admin |
| reference | https://nest-framework.org/docs/reference/modules/admin |

## Using it

In an application's `module.yml`:

```yaml
modules:
  - name: admin
    route: /admin
```
