# Notifications

Toast messages (saved, deleted, sent, failed) after redirects, htmx answers and from page scripts; signed, read once, accessible, restyled by the application.

**Version 0.1.1** · module · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-notifications` |
| name in a manifest | `notifications` |
| category | infrastructure |
| reference | https://nest-framework.org/docs/reference/modules/notifications |

## Using it

In an application's `module.yml`:

```yaml
modules:
  - name: notifications
    route: /notifications
```
