# htmx

A pinned copy of htmx 2.0.4 and htmx-ext-sse 2.2.2, served from the host, configured for a strict Content-Security-Policy (no eval, no inline styles).

**Version 0.1.0** · module · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-htmx` |
| name in a manifest | `htmx` |
| category | ui |
| reference | https://nest-framework.org/docs/reference/modules/htmx |

## Using it

In an application's `module.yml`:

```yaml
modules:
  - name: htmx
    route: /htmx
```
