# Media

Serves stored files with safe headers, pictures at the widths pages need, and gives templates media_url(key, width) and media_srcset(key).

**Version 0.1.0** · module · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-media` |
| name in a manifest | `media` |
| category | content |
| reference | https://nest-framework.org/docs/reference/modules/media |

## Using it

In an application's `module.yml`:

```yaml
modules:
  - name: media
    route: /media
```
