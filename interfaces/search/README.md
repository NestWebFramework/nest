# Search

Index documents and find them again, ranked, with highlighted snippets.

**Version 0.1.1** · interface · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-search` |
| name in a manifest | `search` |
| category | infrastructure |
| reference | https://nest-framework.org/docs/reference/interfaces/search |

## Using it

A module asks for it in its manifest (`requires: interfaces: [search]`); the application binds a provider to it.
