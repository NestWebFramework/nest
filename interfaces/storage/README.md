# Storage

Put, open, stat, list and delete files by key.

**Version 0.1.0** · interface · works with Nest `>=0.2,<1` · licence MIT

| | |
|---|---|
| package | `nest-storage` |
| name in a manifest | `storage` |
| reference | https://nest-framework.org/docs/reference/interfaces/storage |

## Using it

A module asks for it in its manifest (`requires: interfaces: [storage]`); the application binds a provider to it.
